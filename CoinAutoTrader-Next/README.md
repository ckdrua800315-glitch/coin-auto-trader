# CoinAutoTrader-Next v1.15

모의매매 전용입니다. 기존 전략을 운영에서 제외하고 새 진입 3개와 보유 관리 2개로 교체했습니다. 이전 버전 전략 문서는 변경 이력이며 현재 동작 설명은 아닙니다.

- 저점 기반 선행 탐색: 완료 시간봉과 현재 실제 체결의 저점 상승을 함께 확인합니다.
- 오전 9시 초기 상승: 9시 이전 관찰 자료와 3초 지지·실제 체결 가속을 확인합니다.
- 상승 추세 재지지: 15분 상승 구조 안의 높은 저점을 확인합니다.
- 상승 지속 보유·보호 후 증액: 첫 매수 10만원, 보호된 수익 보유분만 설정 상한 안에서 한 차례 증액합니다.
- 매수세 약화 시 분할 익절: 지지선 청산과 수익 보호는 별도로 항상 적용합니다.

## 실행

Node.js 24 이상이 필요합니다. Windows에서는 start.bat으로 시작하고 restart.bat으로 재시작합니다. 현재 가동 중인 프로그램은 시작 버튼을 한 번 더 누르지 말고 재시작을 사용하세요. 서버 종료를 확인한 뒤에만 계좌 파일을 백업하고 다시 실행합니다.

대시보드 접속 주소는 data/dashboard-url.txt에 생성됩니다. 주소와 토큰을 외부에 공개하지 마세요. 원래 계좌 파일을 삭제하지 마세요. 다음 실행 시 과거 거래·현금·보유 수량·투자 한도·손실 예산은 보존하고 전략 선택을 전환합니다. 명시적인 전체 해제 설정은 유지합니다.

9시 이전에 충분히 가동해야 초기 진입 판단이 가능합니다. 체결 자료는 재시작 후 새로 수집합니다. 저점 기반 판단에는 최소 5분의 실제 체결 구조, 추세 재지지에는 약 15분의 구조가 필요합니다. 자료 부족·거래 부족·비용 과다·투자 한도 도달 시 매수하지 않습니다.

## 검사와 재생

npm test는 기능 검사를 실행합니다. node scripts/replay-check.js는 저장된 새 전략 진입·보유 자료를 읽기 전용으로 재생합니다. 신호별 가상 청산 손익을 합산해 전략 성과로 해석하지 마세요.

새 전략은 수익성·무손실·전문가 대비 우월성을 검증한 상품이 아닙니다. 최고점은 사후에 확인되며 급락·호가 공백에서는 손절 예산을 넘을 수 있습니다. 모의매매만 사용합니다. 실전 주문은 비활성화되어 있습니다.

실행 계정·투자 한도·서비스 설정·Docker 배포 구조는 유지했습니다. Docker는 별도 볼륨을 사용하므로 기존 Windows 계좌가 자동으로 복사되지 않습니다.
