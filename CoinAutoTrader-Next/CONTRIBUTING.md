# 수정·검사 안내

이 폴더가 Windows에서 실행하는 최신 모의매매 프로그램입니다. 저장소 루트의 기존 웹 화면·Python 서버와 구분합니다. GitHub에 코드를 저장하는 것만으로 PC에서 실행 중인 프로그램이 업데이트되지는 않습니다.

## 수정할 파일

| 변경 목적 | 파일 |
|---|---|
| 저점 탐색·9시 진입·보유·청산 판단 | `src/morning-strategy.js` |
| 주문 금액·계좌 한도·기록·전략 전환 | `src/engine.js` |
| 실제 체결 이력과 가격 구조 | `src/price-tape.js` |
| 체결·호가 품질 확인 | `src/market-quality.js` |
| 실행 비용·호가 체결 계산 | `src/execution.js` |
| 화면 전략 선택 항목 | `src/strategy-settings.js` |
| 화면 표시·디자인 | `web/app.js`, `web/style.css` |
| 설정 기본값 | `src/config.js` |
| 회귀 검사 | `tests/morning-strategy.test.js` |

## 변경 순서

1. 별도 브랜치에서 수정합니다. 예: `git switch -c fix/entry-timing`.
2. 이 폴더에서 `npm test`를 실행합니다. Node.js 24 이상이 필요하고 별도 패키지 설치는 필요하지 않습니다.
3. 전략 변경에는 진입 가능한 사례와 차단해야 하는 사례를 함께 검사합니다. 미래 시간봉이나 미래 체결을 사용하지 않습니다.
4. GitHub에서 변경 내역과 자동 검사 결과를 확인합니다.
5. 실행 PC에서 검토한 코드를 가져온 뒤 `restart.bat`을 실행합니다. 계좌 데이터는 코드와 별도로 보존합니다.

저장소를 처음 내려받을 때는 기존 실행 폴더를 덮어쓰지 않고 별도 폴더에 받으세요. 새 폴더의 첫 실행은 새 모의 계좌를 만들므로 기존 거래 기록이 자동으로 따라오지 않습니다. 실행 중인 계좌 파일을 임의로 복사하거나 여러 서버에서 동시에 열지 마세요.

## 자동 검사

저장소 루트의 `.github/workflows/coin-auto-trader-next-ci.yml`은 이 폴더 변경 시 Windows와 Linux에서 Node.js 24 검사를 실행합니다. Windows에서는 서비스 프로세스 식별 검사도 실행합니다. 개인 PC 서비스에 배포하거나 재시작하는 작업은 하지 않습니다.

## 업로드하지 않을 파일

`data/`, `logs/`, 접속 토큰, 접속 주소 파일, 계좌 데이터베이스, `.env`, 개인 키, 압축 백업은 업로드하지 않습니다. `.gitignore`는 이미 추적 중인 파일을 제거하지 않으므로, 변경 목록에 이런 파일이 보이면 커밋 전에 제외하세요.

## 성과 설명

검사 통과는 수익성 검증이 아닙니다. 새로운 모의 거래와 이월 보유분을 구분하고, 수수료 포함 손익·최대 낙폭·최고 수익 반납을 기록해야 합니다. 실전 주문을 활성화하거나 수익·무손실을 보장한다고 표시하지 마세요.
